The ESP32 Vehicle Black Box System is a real-time embedded safety and monitoring solution designed to record critical vehicle data and detect accident-related events. Built using an ESP32 microcontroller, the system integrates multiple sensors and communication modules to monitor acceleration, speed, temperature, and GPS location, enabling crash detection, bump logging, over-speed alerts, GSM-based emergency notifications, and SD card data storage. The system also supports IoT cloud integration using ThingSpeak for remote data visualization and monitoring, along with Wi-Fi Access Point mode for local access, demonstrating multi-protocol communication (UART, I2C, SPI) and complete hardware–software integration for automotive safety applications.
